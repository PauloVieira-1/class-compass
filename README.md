# Class Compass 📅

A modern chrome extension built to help users plan, track, and manage their daily activities while seamlessly integrating with chrome.

## 🚀 Features

- **Task Management:** Create, edit, and delete tasks effortlessly and assignments
- **Event Scheduling:** Organize important events and deadlines using reminders and notifications
- **Note Taking:** Take quick notes of important miscellaneous information
- **Reminders:** Never miss important dates
- **Responsive Design:** Works perfectly on most aspect ratios

## 🛠 Tech Stack

- **Frontend:** React.js
- **Styling:** CSS / Bootstrap
- **State Management:** Context API

## 🌐 APIs Used

The Organizer App integrates multiple APIs to deliver a rich user experience:

- **Chrome API:** Enables seamless integration with Chrome for browser-specific features.
- **WeatherAPI.com:** Provides real-time weather data to keep users informed about weather conditions when planning tasks and events.
- **Geoapify API:** Offers geolocation services, enabling location-based functionalities for smarter scheduling and event management.

## 🛠️ Development Dependencies:

- @babel/preset-env: Modern JavaScript support
- @babel/preset-react: Babel preset for React
- webpack & webpack-cli: Module bundler for optimized builds
- prettier: Code formatting
- copy-webpack-plugin, html-webpack-plugin: Build utilities
- webpack-bundle-analyzer: Analyze bundle sizes

## 🚀 Core Dependencies:

- react & react-dom: Core for building user interfaces
- react-big-calendar: Calendar component for task scheduling
- react-bootstrap: UI components based on Bootstrap
- bootstrap: Styling framework
- sass & sass-loader: Advanced styling with Sass
- react-datepicker: Date picker component for scheduling
- sqlite: Lightweight database integration

## 🔧 Installation

To set up the project locally, follow these steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/PauloVieira-1/class-compass
   cd class-compass
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run build
   ```
